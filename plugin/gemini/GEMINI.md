# Maket

When using Maket from Gemini CLI, start by calling:

```text
maket_learn action=overview audience=agent
```

Use `maket_learn action=topics` for the available operating topics. Keep agent onboarding in `maket_learn`; the user-facing onboarding is the built-in Help document opened from the Maket UI.

Install Maket for Gemini with:

```bash
maket install gemini --apply
```
