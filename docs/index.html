02 — Use cases

For what?

To sketch an app

  • One screen per page
  • Notes on any area
  • Assistant applies the notes

To present and report

  • Brand colours and fonts
  • Same resources across projects
  • PDF for screen or print

To make a poster

  • Poster, flyer, brochure, résumé
  • Formats for social media
  • PDF ready to print

To follow a renovation

  • One page per job
  • Form: decision, start date, comment
  • Assistant compares the quotes

To prepare a move

  • One page per task
  • Form: offer, pickup time, note
  • Assistant compares the offers

To look for a flat

  • One page per flat
  • Form: next step, rating, questions
  • Assistant checks the application file

To organize a family event

  • One page per part
  • Form: menu, children, allergies
  • Assistant totals the costs
