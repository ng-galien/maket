03 — How it works

You guide. The agent composes.

You stay in control. The agent handles composition and revisions.

01

Describe what you need

Give the content, format, and mood from your usual AI client. The agent creates the document in Maket.

02

Watch the document take shape

Pages appear in your browser as the agent works. You can check hierarchy, images, and layout right away.

03

Annotate what needs to change

Click an area and leave a note for the agent. For a quick correction, text remains directly editable.

04 — Resources

Your workspace stays ready.

Maket brings together documents, visual identity, images, and data so any agent can pick up the work.

Documents

Posters, presentations, wireframes, and multi-page documents remain available from one session to the next.

Brand guidelines

Apply the same colors, fonts, and visual rules to every document for a brand or project.

Image library

Tag your images with keywords so the agent can find the right assets without relying on filenames.

Data collections

Connect a template to structured data and generate a controlled version for each person, product, or event.

06 — Installation

Connect Maket to your agent.

Copy the ready-made prompt into Codex, Claude, or Gemini. Your agent will install, start, and verify Maket for you.

Read the full guide ↗

# Connect Maket to your agent

$npx -y @ng-galien/maket install claude --apply $npx -y @ng-galien/maket install codex --apply $npx -y @ng-galien/maket install gemini --apply

# Start Maket and open the interface

$npx -y @ng-galien/maket start $npx -y @ng-galien/maket open
